## PROJECT: Random Quote Generator
A single-page web app that fetches and displays a random quote.
Features: new quote button, loading state, error handling,
copy to clipboard, and favorite quotes saved in localStorage.

API USED: Quote Garden
Documentation: https://github.com/pprathameshmore/QuoteGarden

HOW TO RUN:
1. Download or clone the repository.
2. Open index.html in a browser (the portfolio page), then click
   the button to go to app.html.
3. An internet connection is required for fetching quotes.
   The first quote may load slowly while the API wakes up.
