# Random Quote Generator

A single-page web app that fetches and displays a random quote.

## Features

- **New Quote button** that fetches a fresh random quote
- **Loading state** while the request is running
- **Error handling** with a friendly message if the request fails
- **Copy to clipboard** for the current quote
- **Favorite quotes** saved in `localStorage`, so they persist after refreshing the page

**DummyJSON Quotes**
Documentation: https://dummyjson.com/docs/quotes
<br> Endpoint: `https://dummyjson.com/quotes/random`

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a browser (the portfolio page), then click the button to go to `app.html`.
3. An internet connection is required for fetching quotes.
